1Clase del bot

Las clases vienen directamente del enum BotClasses del mod. Las clases heroe tienen raza fija y aspecto no personalizable.

2Raza, genero y apariencia

Elige una clase primero.

⚠️ ADVERTENCIA: Estás usando una combinación raza/clase no oficial (por ejemplo, Enano Chamán o Gnomo Druida). El mod puede no tener sprites, animaciones ni lógica de habilidades preparados para esta combinación. Ejecutar este SQL puede causar errores en el servidor, comportamientos impredecibles en el bot o corrupción de datos en tu base de datos. Asegúrate de tener una copia de seguridad antes de continuar.

3Identidad del NPC

Nombre, nivel, faccion y el ScriptName que veras en creature_template.

El ScriptName vinculará la criatura con la IA C++ del módulo. Asegúrate de elegir el script que corresponda con la clase del bot para un correcto funcionamiento.
Avanzado: rango, clase de stats y gossip

El resto de columnas (velocidades, detection_range, flags_extra, etc.) se rellenan con los valores estandar que usa el propio mod para sus NPCBots, igual que en tu archivo de ejemplo.

?Como usar este SQL en tu servidor

  1. Haz una copia de seguridad de tu base acore_world antes de ejecutar nada.
  2. Ejecuta el SQL generado contra la base world (con HeidiSQL, phpMyAdmin o consola de MySQL).
  3. Reinicia el worldserver, o como GM ejecuta .reload creature_template / .reload all.
  4. En el juego: .npcbot lookup <clase> para localizar tu bot por nombre y entry.
  5. .npcbot spawn <entry> en el mundo (no funciona dentro de instancias) para colocarlo donde estes parado.
